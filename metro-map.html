Shape Vocabulary
Every primitive used to construct metro-map style UIs. Each specimen is rendered with Merlin design tokens.
Station Dot
Circle r=6, line-color stroke, surface fill. Marks a stop on a single line.
Station + Label
Station dot with text below in MArgon 11px. Label fill = --text-primary.
Interchange (2-line)
Outer ring r=10, inner ring r=5 per intersecting line. Bold outline signals transfer point.
Multi-line Interchange
Stacked rings, each colored per intersecting line. Outer r scales +2 per line.
Terminal Node
Outlined pill (rx = h/2), stroke in line color. Label text in line color. Marks line start/end.
H/V Segment
Pure horizontal or vertical polyline segment. The backbone of all routes.
45° Diagonal
Route transition segment at exactly 45°. No bezier — only M H V L path commands.
Orthogonal Bend
L-shaped polyline joining two perpendicular segments. Sharp 90° corner.
Zone Boundary
Dashed rect in --border-muted. Groups related stations. Label in MXenon uppercase.
