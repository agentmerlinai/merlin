Mission Graph Style
Flowchart shape vocabulary and orthogonal edge grammar for mission execution visualizers. ELK Sugiyama layout with standard engineering semantics, styled through Merlin design tokens.
Demo Mission Graph
ELK-backed orthogonal layout with Merlin grid snapping and deterministic SVG routing. Direction: LEFT→RIGHT. All edges are L-shaped or Z-shaped (H/V path commands only — no 45° diagonals). Primary labels are sourced deterministically: string literal first argument (e.g. agent("Analyze", …)) or the required description in spawn("Audit dependencies", missionCode) — no LLM needed for these. LLM synthesizes the intent annotation below each node only when no // comment is present; graph annotations use a readable annotation token stronger than --text-secondary so authored and inferred notes remain legible across themes. Node Shape Vocabulary
Every node kind in the mission graph grammar. Shape carries control-flow class; label carries exact semantic meaning. Color reinforces — never defines — semantics alone.
start / end
Terminal pill (rx = h/2). Outlined in --color-primary. Marks mission entry and exit points.
process
Rounded rectangle rx=4. General root-level statements, declarations, and sequential steps.
agent
Bold-stroke rect + inline agent icon + type chip (top-right). Primary label: string literal first argument (deterministic), or LLM when the argument is opaque (MArgon 11px). Comment annotation: attached below the node via a short dashed stub — the author's // comment shown verbatim, or an LLM-synthesized intent when no comment is present. Both use readable graph annotation text. The annotation is unconstrained by node width and can show a full comment paragraph.
review gate
Human checkpoint station backed by prompt(). User-facing graph text says Review Gate; inspect can still show API: prompt().
opaque-declaration
Dim rect in --bg-muted / --border-muted. Functions, classes, and helpers whose body is not expanded.
decision
Diamond. if/else, switch, ternary. Two or more outgoing branch edges labeled true/false/case.
loop
Process rect + inline loop icon. for/while/do-while. Loop-back edge routes above the node row.
concurrency
Fork/join bar — thick rect (height=6, rx=3) spanning the parallel region. Promise.all / parallel branches.
spawn-boundary
Rect + inline subprocess icon + type chip. Primary label: required spawn(description, missionCode) description (deterministic), or LLM fallback for opaque inferred call sites. Comment annotation: attached above the node via a short dashed stub (placed above when a child container expands below) — the author's // comment shown verbatim, or an LLM-synthesized intent when no comment is present. Both use readable graph annotation text. The annotation is unconstrained by node width and can show a full comment paragraph.
sub-mission-container
Dashed rect (zone boundary style). Header carries the child mission label plus compact source and materialization metadata. Runtime state appears only when the graph represents a live run.
error
Rounded terminator with --color-error stroke and subtle error fill tint. ThrowStmt / catch boundary.
comment
Note box with folded top-right corner, dashed --border-muted stroke. Connects to owning node via annotation edge.
inferred station
Any shape with dashed stroke (stroke-dasharray: 4,2). Marks nodes promoted from opaque boundaries — never implies static expansion.
Station Label Architecture
Each station's label has two tiers. The primary label (1–4 words, bold) follows a deterministic priority chain: a // or /** */ comment above the call wins first; then a string literal first argument (e.g. agent("Analyze", …)); then the required spawn(description, missionCode) description; then options.id / .label / .name; then the identifier name of a code/mission argument (camelCase-split); and finally LLM synthesis only when all deterministic sources fail or produce noise. The comment annotation (attached below the node via a dashed stub) follows the same source rule: author // comment verbatim, or LLM-synthesized intent when no comment exists. LLM results are cached per mission content hash; zero LLM overhead at render time. The annotation is not constrained by node width — it extends into the available space below the node and wraps naturally. Agent, Spawn, Review Gate, and Loop labels may include a semantic Phosphor icon inside the label group; the icon is hidden from accessibility names when the adjacent text already carries the meaning.
